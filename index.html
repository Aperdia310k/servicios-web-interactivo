Servicios Web y Formatos de Datos

Aprende conceptos fundamentales de GET, POST, XML y JSON de forma interactiva.

Conceptos Clave

Petición GET

Se utiliza para recuperar o consultar información del servidor. No debe modificar datos.

Lectura

Petición POST

Se utiliza para enviar o crear nuevos datos en el servidor (formularios, nuevos registros).

Escritura

Formato XML

Lenguaje de etiquetas estructurado. Muy utilizado en sistemas heredados, SOAP y configuraciones estrictas.

Estructurado

Formato JSON

Formato ligero basado en objetos JavaScript. Es el estándar actual en APIs REST debido a su simplicidad.
